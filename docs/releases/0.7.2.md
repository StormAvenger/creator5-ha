# 0.7.2 — Automatic print-complete dismissal

Experimental; use at your own risk. Only Creator 5 Pro has prior physical use.

- **New option (off by default):** automatically dismiss the print-complete screen
  a chosen number of minutes after a print finishes (1–240, default 10). Configure →
  "Automatically dismiss the print-complete screen". Independent of the job-controls
  group.
- Uses the existing acknowledgement command: one attempt per completion, only while
  the printer still reports completed, verified by status readback, never retried.
  Pressing the button yourself or starting a new print cancels the countdown.
- **Trade-off:** dismissing tells the printer the bed is clear. Afterwards a print
  sent remotely could start on a part left on the bed. Starting prints at the
  printer is unaffected. See the [controls guide](../controls.md).
