# 0.3.4 — Job information and on-demand model preview

Experimental; use at your own risk. Only Creator 5 Pro has prior hardware testing;
standard Creator 5 remains hardware-unverified.

- Add current print filename and estimated finish time from the shared status poll.
- Hide stale idle filenames and clear finish time outside active printing. Frozen
  status estimates do not slide forward on repeated polls.
- Add reported lifetime printing time (hours, converted from minutes) and reported
  free storage (GB), with units based on Creator 5 community observations. Physical
  display comparison on firmware 1.9.9 remains pending.
- Add an on-demand current-print thumbnail image through HA, using only the fixed
  printer endpoint, bounded PNG/JPEG reads, no redirects, no credentials and a
  one-minute per-job in-memory cache. No polling-time image requests or recording.
- Include an optional native job-information card example. Existing dashboards,
  printer configuration, material mappings and disabled entities are preserved.

Pro registers 58 entities, 57 enabled by default with camera enabled. The only
printer control remains chamber light. No new control services are added.

This candidate is validated locally; live thumbnail validation and installation
are pending owner activation approval. The previous 0.3.2 runtime/HACS acceptance
does not establish live acceptance of these new features. See
[job-monitoring details](../job-monitoring.md) for privacy, unit and cache behavior.

Validation: 124 standalone tests and 49 real HA 2026.10.1 tests pass (173 total).
All 49 HA tests pass again from a clean source snapshot. The built 0.3.4 wheel
passes the 124 client tests. Lint, formatting, client typing, source/wheel build
and official HA 2026.10.1 hassfest pass. Tests use synthetic data, with external
HA sockets blocked. A live thumbnail check was blocked by automatic approval
review under the earlier status-only access rule; no live image was retrieved.
