# 0.4.0 — Optional controls and quieter monitoring

Experimental; use at your own risk. Published at the owner’s request after offline
validation. This release has not been installed or physically tested by the agent. Creator 5 Pro monitoring is observed on firmware
2.0.0; that firmware currently has an owner-reported light-control timeout.

- Add reported lifetime filament, speed multiplier, signed Z offset, auto-shutdown
  status/delay and material-station slot/activity codes.
- Classify layers and progress as continuous measurements, preserving readings and
  history while suppressing excessive native Activity entries.
- Add four control groups, all off by default: pause/resume/completion acknowledgement,
  slot material/color settings, speed/auto-shutdown settings, and Celsius heater targets.
- Completion acknowledgement is only explicit or called by an owner-created automation.
  It is never automatic and never starts a print. No cancel/start controls are included.
- Serialize polling/control operations; guard new controls using fresh model/state;
  bound inputs; preserve untouched fields and verify results rather than trusting ACKs.
- Improve light/control failure messages and cached failure-stage diagnostics without
  credentials, arbitrary response text or automatic command retries.

Pro registers 65 entities (64 enabled with camera enabled) with new control groups
all off. Enabling all four groups adds 20 native control entities. Existing entity
IDs, manual mappings, dashboards, disabled-entity preferences and credentials are retained.

New writes remain physically unverified. Firmware 2.0.0 light control is **not
claimed fixed**. See [controls and acceptance plan](../controls.md).
