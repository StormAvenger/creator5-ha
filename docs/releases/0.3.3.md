# 0.3.3 — Experimental public release

This release packages the existing 0.3.2 functionality with clearer installation,
compatibility, dashboard and contribution documentation. Runtime behavior is unchanged.

- Prominent experimental/use-at-your-own-risk notice and AI-assisted development disclosure.
- Structured HACS installation, printer setup, settings, updates and troubleshooting guide.
- Creator 5 Pro is the only hardware-tested model; standard Creator 5 remains unverified.
- Material-slot dashboard examples remain optional and separate from HACS installation.
- Integration and standalone package versions advance from 0.3.2 to 0.3.3.

The maintainer is running the preceding runtime successfully on a Creator 5 Pro
with HA 2026.10.1 and API firmware 1.9.9. Software is provided without warranty;
feedback and contributions are welcome. No additional printer controls are introduced.

A review of tracked files and reachable branch history found no known owner
credentials, printer identifiers, home IP/HA address, MAC addresses or raw diagnostic
files. IP literals are synthetic test addresses or standard network ranges. This
review does not establish deletion of previously disclosed PR-linked commit metadata
or cached GitHub objects. No paid GitHub services or hosted workflows are used.

Validation for 0.3.3: 102 standalone tests and 45 HA 2026.10.1 runtime tests
pass (147 total). Local lint, formatting, typing, source/wheel build and matching
version/license metadata checks pass. Builds reused the existing local build tools.
The 0.3.2 HACS and physical Pro acceptance remains the runtime evidence because
this patch changes documentation and version metadata only. It has not been
installed on the maintainer's HA host as part of this release.
