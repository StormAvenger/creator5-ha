# 0.5.0 — Guided setup and useful print information

Experimental; use at your own risk. Only Creator 5 Pro has owner-reported hardware
use. Standard Creator 5 remains hardware-unverified. The six additions below have
local automated coverage; they have not been installed or exercised by the agent
on the owner's live HA host. The firmware 2.0.0 light-control issue is not claimed fixed.

- Add an administrator-only **Creator 5 setup** page to create a native dashboard
  with the actual printer entity IDs, grouped material swatches, camera and enabled
  controls. Existing dashboards/panels are preserved.
- Retain one last-print summary through reloads, including reported duration,
  completion-observed time and incomplete-observation labeling. Unknown outcomes
  are not treated as successful prints.
- Add a configurable bed-cooled indicator (default below 40 °C with the target off)
  and a once-per-completion event. This describes the bed only.
- Add guided opt-in alerts for completion, cooling, new errors, prolonged pauses,
  lost connections and due maintenance. The native automation can be edited or
  disabled in HA. No automatic alerts or printer actions are installed at setup.
- Add three user-defined printing-hours maintenance intervals, remaining/due entities
  and local record-service buttons. Counter resets invalidate old baselines.
- Add selected, vendor-verified error explanations and suggested checks while
  retaining original codes and a clear fallback for unrecognized meanings.

Pro registers 77 entities, 76 enabled by default with camera enabled and all new
printer-control groups off. All four printer-control groups add the existing 20
controls. No additional printer command is introduced by 0.5.0. Existing manual
mappings, disabled entities, credentials and dashboards are retained.

Privacy: one bounded previous-job record and maintenance state stay in HA storage.
Filenames are excluded from integration diagnostics and generated notifications.
See [setup, behavior and limitations](../usability.md).
