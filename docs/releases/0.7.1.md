# 0.7.1 — Stability

Experimental; use at your own risk. No new features, entities or printer commands.

- **Brief glitches are ignored.** One or two missed status replies in a row keep
  the last reading instead of making every entity unavailable, so a marginal
  Wi-Fi link no longer makes dashboards flicker or fills history with gaps.
  Readings go unavailable on the third consecutive failure (about 30 s at the
  default interval). A glitch during a print still marks that print's record as
  incompletely observed. Rejected credentials get no grace.
- **Less polling while the printer is off.** After readings go unavailable,
  polling slows to once a minute and returns to the normal interval as soon as the
  printer answers. Diagnostics show the current interval and consecutive failures.
- **Simpler internals.** Alerts, alert timers and alert pictures moved from the
  coordinator into their own module; control commands share one status-publishing
  path. Behavior is unchanged.
- **Maintenance.** CI now also tests weekly against the newest Home Assistant
  release, and Dependabot proposes updates to pinned actions and test dependencies.
- **Agent docs.** AGENTS.md is now a current rulebook for AI agents; the dated log
  moved to docs/agent-history.md.
